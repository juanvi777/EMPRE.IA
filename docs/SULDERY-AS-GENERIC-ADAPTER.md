# Suldery como primer adaptador del Connector universal

Suldery Nails no es un conector especial dentro de EMPRE. Se conecta usando `generic_rest` y un conjunto de herramientas que mapean sus endpoints reales.

El objetivo de esta prueba es verificar que, después de hacer el primer adaptador, el mismo motor puede recibir otra empresa con otras rutas y otras capacidades sin cambiar el núcleo de EMPRE.
