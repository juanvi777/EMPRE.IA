# Guía de conexión de EMPRE.IA

Usa el botón flotante **Guía** del robot para abrir esta ayuda.

### Para el dueño
Pide a EMPRE preparar una integración, revisa el plan y aplica el borrador. La conexión no se activa hasta completar autenticación y verificación.

### Para el desarrollador
Debes exponer una API, SDK/Connector o webhook con funciones claramente delimitadas. Empieza por health, identidad/autenticación y un manifest de herramientas cuando sea posible.

### Regla de seguridad
Una URL no implica permisos. Una conexión tampoco implica acceso ilimitado. EMPRE sólo utiliza herramientas declaradas, autorizadas y verificadas.
